# Opera Flix

SPA inspirada em interfaces de streaming, desenvolvida em **React** com foco em desempenho e navegação fluida. Projeto de interface web (Create React App).

## Stack

- React 16, React Router, styled-components
- react-slick (carrosséis)
- Jest / Testing Library (template CRA)

## Pré-requisitos

- Node.js (LTS recomendado)
- npm

## Como rodar

```bash
npm install
npm start
```

Abra [http://localhost:3000](http://localhost:3000). Para build de produção: `npm run build`.

## Scripts úteis

| Comando | Descrição |
|--------|-----------|
| `npm start` | Servidor de desenvolvimento |
| `npm test` | Testes em modo interativo |
| `npm run build` | Build otimizado em `build/` |
